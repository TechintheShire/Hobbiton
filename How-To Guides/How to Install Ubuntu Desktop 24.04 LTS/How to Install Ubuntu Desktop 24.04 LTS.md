## [1] 💿 Download the Ubuntu Desktop 24.04 LTS ISO.

- Download the Ubuntu Desktop 24.04 LTS ISO using your `🌐 web browser`.

  ```bash
  https://releases.ubuntu.com/24.04/
  ```

## [2] ⬇️ Install Ubuntu Desktop 24.04 LTS.

> [!TIP]
> If you are installing Ubuntu Desktop on a physical machine, I recommend writing the ISO to a bootable USB drive using `Rufus`.
> ```bash
> https://rufus.ie/en/#download
> ```

- Boot from the Ubuntu Desktop 24.04 LTS ISO.

  <a href="./Media/Screenshot%202025-10-19%20094516%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20094516%20v2.png" height="270"/>
  </a><br>

  <a href="./Media/Screenshot%202025-10-19%20094621%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20094621%20v2.png" height="270"/>
  </a><br>

- Select your language, then click `Next`.

  <a href="./Media/Screenshot%202025-10-19%20094813%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20094813%20v2.png" height="370"/>
  </a><br>

- Select any accessibility aids, if needed, then click `Next`.

  <a href="./Media/Screenshot%202025-10-19%20094855%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20094855%20v2.png" height="370"/>
  </a><br>

- Select your keyboard layout, then click `Next`.

  <a href="./Media/Screenshot%202025-10-19%20094912%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20094912%20v2.png" height="370"/>
  </a><br>

- Select your method for connecting to the internet, then click `Next`.

  <a href="./Media/Screenshot%202025-10-19%20094932%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20094932%20v2.png" height="370"/>
  </a><br>

- If prompted, click `Update now` to update the installer snap package.
- Once the update finishes, click `Close installer`. Then, relaunch the installer using the `Install Ubuntu 24.04 LTS` desktop icon.
- If no installer update is available, continue with the installation.

  <a href="./Media/Screenshot%202025-10-19%20095003%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20095003%20v2.png" height="370"/>
  </a><br>

  <a href="./Media/Screenshot%202025-10-19%20095033%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20095033%20v2.png" height="370"/>
  </a><br>

- Open the `Install Ubuntu 24.04 LTS` icon on the desktop to 🔄 restart the installation.

  <a href="./Media/Screenshot%202025-10-19%20095055%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20095055%20v2.png" height="370"/>
  </a><br>

- Reselect your preferred `language`, `accessibility`, `keyboard`, and `internet connection` settings.
- Select `Interactive installation`, then click `Next`. 

  <a href="./Media/Screenshot%202025-10-19%20095220%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20095220%20v2.png" height="370"/>
  </a><br>

- Select `Default selection`, then click `Next`.

  <a href="./Media/Screenshot%202025-10-19%20095240%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20095240%20v2.png" height="370"/>
  </a><br>

- Select the following installation options:
  - `Install third-party software for graphics and Wi-Fi hardware`. 
  - `Download and install support for additional media formats`. 
- Then, click `Next`.

  <a href="./Media/Screenshot%202025-10-19%20095258%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20095258%20v2.png" height="370"/>
  </a><br>

- Select `Erase disk and install Ubuntu`, then click `Next`.

  <a href="./Media/Screenshot%202025-10-19%20095314%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20095314%20v2.png" height="370"/>
  </a><br>

- Configure your account and machine information.
  - Enter your `name`.
  - Enter a `computer name` (hostname).
  - Choose a strong `password`. 
  - Keep `Require my password to log in` selected. 
- Click `Next`.

  <a href="./Media/Screenshot%202025-10-19%20095418%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20095418%20v2.png" height="370"/>
  </a><br>

- Select your time zone, then click `Next`. 

  <a href="./Media/Screenshot%202025-10-19%20095438%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20095438%20v2.png" height="370"/>
  </a><br>

- Review your installation settings. 
- When ready, click `Install`. 

  <a href="./Media/Screenshot%202025-10-19%20095454%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20095454%20v2.png" height="370"/>
  </a><br>

  <a href="./Media/Screenshot%202025-10-19%20095511%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20095511%20v2.png" height="370"/>
  </a><br>

- Once installation is complete, click `Restart now`.

  <a href="./Media/Screenshot%202025-10-19%20095649%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20095649%20v2.png" height="370"/>
  </a><br>

- When prompted, eject (remove) the installation media or detach the ISO, then press `ENTER`.

  <a href="./Media/Screenshot%202025-10-19%20095719%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20095719%20v2.png" height="270"/>
  </a><br>

- Once Ubuntu finishes rebooting, you'll see a login screen.

  <a href="./Media/Screenshot%202025-10-19%20095816%20v2.png">
    <img src="./Media/Screenshot%202025-10-19%20095816%20v2.png" height="370"/>
  </a><br>

## 🎉 Congratulations!

You have successfully installed Ubuntu Desktop 24.04 LTS!

Your system is now ready to use. Enjoy exploring Ubuntu and everything it has to offer!
