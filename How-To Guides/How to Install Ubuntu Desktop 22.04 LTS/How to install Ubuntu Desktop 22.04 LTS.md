# How to Install Ubuntu Desktop 22.04 LTS

> [!WARNING]
> Ubuntu 22.04 LTS receives standard security updates through May 2027. For a new installation, consider using a newer Ubuntu LTS release unless you specifically require Ubuntu 22.04 LTS for compatibility.

## [1] 💿 Download the Ubuntu Desktop 22.04.5 LTS ISO

- Download the Ubuntu Desktop 22.04.5 LTS ISO using your `🌐 web browser`.

  ```bash
  https://releases.ubuntu.com/22.04/
  ```

## [2] ⬇️ Install Ubuntu Desktop 22.04.5 LTS

> [!TIP]
>  If you are installing Ubuntu Desktop on a physical machine, I recommend writing the ISO to a bootable USB drive using `Rufus`.
> ```bash
> https://rufus.ie/en/#download
> ```

- Boot from the Ubuntu Desktop 22.04.5 LTS ISO.

  <a href="./Media/Screenshot%202025-12-09%20085104%20v2.png">
    <img src="./Media/Screenshot%202025-12-09%20085104%20v2.png" height="270"/>
  </a><br>

  <a href="./Media/Screenshot%202025-12-09%20085152%20v2.png">
    <img src="./Media/Screenshot%202025-12-09%20085152%20v2.png" height="270"/>
  </a><br>

- Select your language, then click `Install Ubuntu`.

  <a href="./Media/Screenshot%202025-12-09%20085402%20v2.png">
    <img src="./Media/Screenshot%202025-12-09%20085402%20v2.png" height="370"/>
  </a><br>

- Select your keyboard layout, then click `Continue`.

  <a href="./Media/Screenshot%202025-12-09%20085423%20v2.png">
    <img src="./Media/Screenshot%202025-12-09%20085423%20v2.png" height="370"/>
  </a><br>

- Select the following installation options:
  - `Normal installation`.
  - `Download updates while installing Ubuntu`.
  - `Install third-party software for graphics and Wi-Fi hardware and additional media formats`.
- Then, click `Continue`. 

  <a href="./Media/Screenshot%202025-12-09%20085450%20v2.png">
    <img src="./Media/Screenshot%202025-12-09%20085450%20v2.png" height="370"/>
  </a><br>

- Select `Erase disk and install Ubuntu`.
- Then, click `Install Now`.

  <a href="./Media/Screenshot%202025-12-09%20085528%20v2.png">
    <img src="./Media/Screenshot%202025-12-09%20085528%20v2.png" height="370"/>
  </a><br>

- Confirm the `Write the changes to disk?` prompt by clicking `Continue`.

  <a href="./Media/Screenshot%202025-12-09%20085549%20v2.png">
    <img src="./Media/Screenshot%202025-12-09%20085549%20v2.png" height="370"/>
  </a><br>

- Select your time zone, then click `Continue`.

  <a href="./Media/Screenshot%202025-12-09%20085621%20v2.png">
    <img src="./Media/Screenshot%202025-12-09%20085621%20v2.png" height="370"/>
  </a><br>

- Configure your account and machine information.
  - Enter your `name`.
  - Enter a `computer name` (hostname).
  - Enter a `username`.
  - Choose a strong `password`.
  - Keep `Require my password to log in` selected.
- Click `Continue` to begin installing Ubuntu.

  <a href="./Media/Screenshot%202025-12-09%20085741%20v2.png">
    <img src="./Media/Screenshot%202025-12-09%20085741%20v2.png" height="370"/>
  </a><br>

  <a href="./Media/Screenshot%202025-12-09%20090046%20v2.png">
    <img src="./Media/Screenshot%202025-12-09%20090046%20v2.png" height="370"/>
  </a><br>

- Once the installation is complete, click `Restart Now`.

  <a href="./Media/Screenshot%202025-12-09%20090144%20v2.png">
    <img src="./Media/Screenshot%202025-12-09%20090144%20v2.png" height="370"/>
  </a><br>

- When prompted, eject (remove) the installation media or detach the ISO, then press `ENTER`.

  <a href="./Media/Screenshot%202025-12-09%20090211%20v2.png">
    <img src="./Media/Screenshot%202025-12-09%20090211%20v2.png" height="270"/>
  </a><br>

- Once Ubuntu finishes rebooting, you'll see a login screen. <br>

  <a href="./Media/Screenshot%202025-12-09%20090320%20v2.png">
    <img src="./Media/Screenshot%202025-12-09%20090320%20v2.png" height="370"/>
  </a><br>

## 🎉 Congratulations!

You have successfully installed Ubuntu Desktop 22.04 LTS!

Your system is now ready to use. Enjoy exploring Ubuntu and everything it has to offer!
